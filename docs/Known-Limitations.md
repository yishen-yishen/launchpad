# 已知限制与未完成项

这是一版已可构建的开发实现，不是规范 M0–M5 全部完成的 v1。不能用逻辑测试通过代替交互验收。

## P0 尚需实现

- 横向翻页当前为滚轮阈值离散切页，没有跟随手指的连续投影、吸附和完整 phase 状态机。
- 拖动使用原生 collection view 预览，释放前不改变布局；中央悬停建文件夹和边缘翻页已接入，但缺少完整占位投影、末页临时页、自动展开已有文件夹并内部定位、从文件夹直接拖到根投影、Esc 主动终止原生拖动。可用原生取消和键盘菜单移入/移出。定时依赖真实日期，未注入测试时钟。
- 已补上 500 ms 长按入口，以“完成”按钮表示编辑状态（已移除蓝底/蓝框）；原生检查覆盖长按进入整理，编辑期间单击只选择。真实拖动排序/悬停建文件夹仍待手工验收。
- 文件夹当前在主内容区替换显示，不是居中压暗材质弹层。根页位置已独立保存。
- 多屏改变时还需完善拖动取消、安全区密度重算、首可见锚点和无屏幕处理的交互验证。网格密度/图标大小尚需视觉校准。
- 关闭启动器不再主动激活其他应用；首次聚焦和 Tab、网格跨页选择、搜索结果滚动选中仍需全面交互测试。
- 不可用条目缺少完整变暗、运行状态和移除/重新定位对话框；同名副本未显示来源辅助标签。
- 偏好使用 UserDefaults，尚未改为版本化 preferences.json；布局没有历史已发布格式，因此暂无旧格式迁移。高版本布局保护和损坏备份恢复已有测试。
- VoiceOver 目前仅基本按钮名称/角色，尚缺状态、文件夹数量/展开语义、原生可访问动作及 UI 自动化覆盖。
- 尚未接入分分类 OSLog、完整 signpost、debug 状态面板和 debug 300/1000 项压力注入。不可把性能目标视为测量结果。
- 正式原创 AppIcon 尚未制作，当前使用系统默认开发图标。

## 已接入但待真机验证

全局快捷键冲突与 Secure Input、中文候选/组合输入优先级、多屏/拔屏/刘海/全屏 Space/Stage Manager、登录 Apple event 是否可靠区分手动打开、辅助功能设置、菜单与文件面板焦点、窗口反复显示隐藏、启动目标成功/失败和已运行情况。登录事件不足时必须改 helper。

## P1 状态

拼音缓存、20 次会话撤销、隐藏/恢复、JSON 导入导出预览及备份、受限第三方应用废纸篓入口已有代码。导入身份匹配只用 bundle ID + 名称唯一候选，歧义保留占位；不包含路径，不能将导入内容直接启动。多音字按系统转写，不保证语义准确。P1 尚未独立 GUI 验收，尤其废纸篓从未对用户应用实际执行。

## 明确不支持 / 研究项

系统原版捏合手势、旧 Launchpad 数据迁移、App Store 安装进度均未实现，单独研究，不阻塞 P0。无网络、云同步、更新管理、卸载残留清理、嵌套文件夹、权限提升或私有数据库访问。没有已签名/公证产物。
