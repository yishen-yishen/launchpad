## 免录屏版本验证（2026-11-12，替代旧授权步骤）

1. 使用当前build/Development/LaunchDock.app；系统录屏列表不需要添加LaunchDock。旧版本授权可移除，应用不再提供录屏授权按钮或调用权限申请。
2. 执行 `sh scripts/check-wallpaper-no-permission.sh`：必须screenRecordingGranted=false、hasContent=true；打开输出的wallpaper-preview.png，应是当前壁纸且没有应用/菜单栏/Dock/桌面图标。
3. 静态PNG/JPEG、动态HEIC分别测试；显示期间固定，关闭再打开刷新。切换壁纸/显示器/Space后检查匹配。检查设置中的背景来源和文件回退说明。
4. 若兼容接口不可用，必须使用有效主图或纯色，不弹录屏授权、不临时隐藏其他应用。
5. macOS27需单独运行同一探针验证私有兼容分支；未知未来系统文件回退，不将本机26结果泛化。


## 原生测试及全屏 Space 回归（2026-11-12）

- 先执行 `sh scripts/build-dev.sh`，再执行 `sh scripts/check-native.sh`。脚本默认读取仓库 build/Development，也可传入其他构建目录；从其他工作目录调用同样有效。
- `LAUNCHDOCK_CHECK_LIFECYCLE=1 sh scripts/check-native.sh` 额外验证设置、显示隐藏及独立辅助应用层级。
- `sh scripts/check-fullscreen.sh` 会打开独立辅助 App 并短暂进入全屏 Space。请在可允许测试切换 Space 时运行；辅助窗口自动关闭。测试驱动经 Launch Services 作为独立 App 启动，不能用裸 Cocoa CLI 的前台身份替代。
- 每轮输出独立诊断目录，保留 check.log/fullscreen state.json。检查失败必须 FAIL + 非零退出码，不能输出 ALL NATIVE CHECKS PASSED；open -W 本身不传播 App 退出码，因此脚本另查结果文件。辅助程序响应 quit 标记，另有 120 秒超时退出保护。
- 测试框架报错通道：`LAUNCHDOCK_CHECK_FORCE_FAILURE=1 sh scripts/check-native.sh` 应返回 1 并打印 Intentional harness failure-path check，不应弹系统崩溃报告。这是故意失败，不能算产品回归通过。
- 人工验收：Chrome 进入全屏视频独立 Space，从触发角/快捷键唤起，输入搜索并 Esc 关闭；应始终留在该视频 Space。再测从 Dock 唤起、多屏、Stage Manager、DRM 视频。系统拒绝覆盖的场景记录限制，不强切 Space。

## 设置与文件夹改名（1.0.1）

1. 通用页仅在此提供触发角：下拉选择关闭/四角之一；不再需要 Option。旧版曾启用 Option 的用户升级后直接移入角落应能触发。
2. 分别开关“隐藏菜单栏图标”“隐藏 Dock 图标”，应立即生效、可恢复、重启后保留。两者都隐藏时通过全局快捷键、触发角或从访达打开 App 唤起，再在空白区域右键进入设置。
3. 通用页没有“测试显示入口”；外观页没有浅色/深色选择，系统外观改变时控件遵循系统。壁纸上图标文字保留白色以保持可读性。
4. 打开文件夹后单击顶部名称：可选中输入，Enter 保存、Esc 取消；点击其他区域或离开启动器提交有效名称。空白/超过40字符不能覆盖原名。关闭、重新打开及重启后名称应保留，扫描实体目录不覆盖手动改名。
5. 根网格中的应用/文件夹标签仍不能编辑或选择，只有打开文件夹后的标题可改名。中文输入法候选确认与取消、VoiceOver、隐藏 Dock 后不同全屏视频场景需人工验收。

## 点击启动与图标缓存（2026-11-13）

- 点击未运行的应用：图标短暂放大，随后启动器关闭；目标应用可继续加载，不应等待目标窗口出现才关闭。慢启动期间重开启动器，目标完成启动时不能再次把它关掉；启动失败须能看到错误。
- 首次升级允许后台建立图标缓存；退出并重新打开后应先看到缓存图标，再检查应用更新。替换实际图标资源后重扫，应保留旧图直到新图就绪，文件夹预览也应刷新。
- 缓存位于 ~/Library/Caches/app.launchdock.LaunchDock/Icons-v1，可由系统清理；不含布局数据。缓存损坏或不可写不应影响应用启动和布局保存。
- 真正开机后的首次打开速度、低速磁盘/大量应用及多屏色彩仍需人工体验；不能用热缓存测试代替冷开机结论。
