# LaunchDock

[English](README.en.md) | 简体中文

**让常用应用，触手可及。**

LaunchDock 是一款原生 macOS 应用启动器。用熟悉的图标网格浏览应用，输入名称快速搜索，直接拖拽整理自己的常用工具。

## 主要功能

- **快速打开**：通过 Dock、菜单栏、快捷键或触发角唤起启动器。
- **即时搜索**：输入应用名称，快速找到并启动应用。
- **自由整理**：拖动图标调整顺序，叠放应用创建文件夹；打开文件夹后点击标题即可改名。
- **轻松移出文件夹**：拖到文件夹外停留约 300ms，自动回到主页面，继续拖动并选择放置位置。
- **整页翻页**：支持滚轮、触控板、空白区域横向拖动及底部分页圆点。
- **融入桌面**：自动读取系统壁纸并模糊；支持调整图标大小、隐藏 Dock 或菜单栏图标，以及登录时启动。
- **布局随你保存**：自动保存排列，支持布局导入、导出与撤销最近整理。

## 安装

要求 **macOS 26.0 或更高版本**。通用安装包支持 Apple Silicon 和受该系统支持的 Intel Mac，无需安装 Xcode、Homebrew 或其他依赖。

1. 在 [Releases](https://github.com/yishen-yishen/launchpad/releases) 查看安装包，下载 `LaunchDock-0.0.1-beta-universal.dmg`。
2. 退出正在运行的旧版 LaunchDock，打开 DMG，将 **LaunchDock** 拖入 **Applications（应用程序）**。
3. 弹出磁盘镜像，从“应用程序”打开 LaunchDock。

当前版本为 **0.0.1-beta**，使用本地 ad-hoc 签名，尚未通过 Apple 公证。首次打开若被 macOS 阻止，请在确认下载来源可信后，按“系统设置 → 隐私与安全性”中的提示允许打开。不需要关闭系统安全保护。

## 开始使用

| 操作 | 使用方式 |
| --- | --- |
| 打开 / 关闭启动器 | 默认快捷键 `Option + Space`，或点击 Dock / 菜单栏图标 |
| 设置触发角 | 在“设置 → 通用”选择一个角；移入角落即可切换显示 / 隐藏 |
| 启动应用 | 点击应用图标或名称；也可以先输入名称搜索 |
| 整理应用 | 直接拖动图标；拖到另一个应用上松手可创建文件夹 |
| 关闭文件夹 | 点击文件夹外的空白处，或按 `Esc` |
| 打开设置 | 点击搜索框右侧按钮，或在空白处右键选择“设置…” |
| 在访达中定位 | 右键点击应用，选择“在访达中显示” |

搜索时按 `Esc` 会先清空搜索。应用安装或卸载后，可在“设置 → 应用”中重新扫描。若同时隐藏 Dock 与菜单栏图标，请保留可用的快捷键或触发角入口。

## 隐私与数据

LaunchDock 无需账号，不包含联网服务或遥测。应用扫描、搜索、布局和图标缓存均在本机处理；读取壁纸不申请屏幕录制权限。

替换 `.app` 升级不会删除已有布局。卸载时退出 LaunchDock，再将应用移到废纸篓；个人布局仍保留在 `~/Library/Application Support/app.launchdock.LaunchDock/`。导出的布局可能包含本机应用信息，分享前请自行检查。
